### What I would look at first

**[V-DEX](https://github.com/Vrixton/v-dex)** — my portfolio, built as a handheld
device. Two bezels driven by a state machine close over the screen on every
navigation, every sound is synthesized with the Web Audio API, the pixel art is
drawn for the project, and it reads in English and Spanish from typed catalogs
where a missing translation does not compile. It installs as an app.
→ [v-dex.vercel.app](https://v-dex.vercel.app)

**[pixel-pet](https://github.com/Vrixton/pixel-pet)** — a React pixel art
companion, published on npm. Controlled state rather than hidden storage, the
full ARIA menu pattern, a walk cycle whose frames follow distance travelled
instead of a separate clock, and sprite paths escaped during server rendering
to prevent CSS injection. Verified in Chromium, Firefox and WebKit.
→ [Live demo](https://pixelpet-eight.vercel.app/) · [`npm i @vrixton/pixel-pet`](https://www.npmjs.com/package/@vrixton/pixel-pet)
